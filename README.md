# 字趣

一个给孩子在本地使用的语文字词与古诗默写工具。孩子在屏幕上选择当前课次，听题后把答案写在自己的本子上，再根据完整答案自行批改。

## 现在的流程

1. 孩子在默写首页选择年级、册别和当前课次。
2. “当课复习”默认要求默写词语中的每个字及拼音，播放阶段不显示答案。每次播放会读两遍，第一遍结束 10 秒后读第二遍；空格播放或停止，左右键切换题目，上下键切换每组 4 题。播音直接使用浏览器自带的中文语音，不调用服务端语音接口。
3. 没听清时可以查看提示；查看后只统计仍需独立默写的目标字，提示字不记为本次写对，但批改时仍可主动标错。未查看提示时，整词未标错的字都记为正确；这些已经覆盖并掌握的字，对应题目会排在其他未覆盖题目之后。
4. “历史复习”从后往前选取 20 个词，优先练到期错字；未通过的错字每次复习后，至少间隔 7 天才再次出现。
5. 生字按“写对次数 − 写错次数”计算净正确次数，达到 1 即通过；例如错 2 次，需要累计写对 3 次。同一场默写中，同一个字即使出现在多个词里，也只累计一次作答结果。
6. 古诗只显示题目拼音，题目、朝代、作者和全文都由孩子默写，不播放语音。
7. 同一次默写中，只要任意默写字出现在课文题目里，页面主标题和该课所有题卡都会持续把对应字替换为拼音，避免其他题泄露答案；批改时恢复中文题目。
8. 孩子写完后点击“结束默写”，根据完整答案点选错字并保存。保存后进入订正页：页面显示完整错词并标红错字；第一次写错订正 2 遍，以后每错一次增加 1 遍。
9. 家长看板会汇总打卡、正确率和全部待巩固错字；错字按默写词语归类，不再省略较早的错词。另有“历史错词”统计和完整清单，词语掌握后仍保留，并区分“待巩固 / 已掌握”。两份清单都可一键单独打印。
10. 历史复习保存后如果漏标了错字，可在“家长看板 → 最近默写”展开对应记录并点击“补记错字”。更正会直接修改原记录：作答次数不增加，只把选中的字从正确改为错误，并同步更新待巩固状态。新记录会保存当场题词和实际计分字；旧记录按当前词库还原，原来判为全对的目标字可直接补记，旧版已整词计错的题不会重复累计。

## 词库

当前词库只以以下 Markdown 文件为权威数据源：

- `md/词语/*.md`
- `md/古诗文/*.md`

修改 md 后重建数据库：

```bash
npm run rebuild:data
```

如果需要同时清空全部学习记录：

```bash
npm run rebuild:all
```

数据仍保存在本地 SQLite 中：

- `data/ziqu-catalog.sqlite`：由 md 重建的课本词库。
- `data/ziqu-learning.sqlite`：当前课次、默写记录和错字记录。

## 运行

```bash
npm install
npm run dev
```

然后打开终端中显示的本地地址。

生产运行：

```bash
npm run build
npm run start
```

## 部署到服务器

可以直接使用 Docker 启动网站：

```bash
docker compose up -d --build
```

默认访问端口是 `5174`。学习记录保存在 Docker 数据卷 `ziqu-data` 中，更新容器不会丢失；课本词库会随镜像一起更新。播音仍由访问网页的浏览器提供，因此服务器不需要部署语音模型，也没有语音接口费用。
