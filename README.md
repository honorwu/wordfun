# 字趣

一个给孩子在本地使用的语文字词与古诗默写工具。孩子在屏幕上选择当前课次，听题后把答案写在自己的本子上，再根据完整答案自行批改。

## 现在的流程

1. 孩子在默写首页选择年级、册别和当前课次。
2. “当课复习”先按课本顺序默写本课词语表中的全部词语，再检查这些词语覆盖了哪些识字表、写字表的字，只为遗漏生字补充组词题；同词同拼音合并为一题。词语表整词都是目标字，补充组词以遗漏生字为目标。默认要求默写词语中的每个字及拼音，整次默写的题目都列在同一页，播放阶段不显示答案。每次播放会读两遍，第一遍结束 10 秒后读第二遍；空格播放或停止，左右键切换当前题目。播音直接使用浏览器自带的中文语音，不调用服务端语音接口。
3. 词语有教材可挖空的句子时，默写一开始就显示。红色（　）表示本题词语，本轮其他答案用拼音代替。看句子不算查看拼音提示。“当课复习”点开拼音提示后，仍可标出整词任意错字。无错但只评了部分字时，记录本次练习，整题仍待独立验证。
4. “历史复习”从本课之前的题里最多选 20 题，每轮最多 5 道到期复练题，其余选待完成整题的题目。复练间隔为 5 天（120 小时）。本题有整词错误记录时，题卡标「曾写错」。仅因某个字曾写错而安排的词语标「错字复练」。相同词语在不同课有各自的题目 ID 和学习状态。
5. 批改时，词语的任一字写错都使本题记错一次，同时记录具体错字。整题按“写对次数 − 写错次数”计算净正确次数，达到 1 即掌握。例如错 2 次，需要累计整题做对 3 次。
6. 古诗词只在当课做整篇默写，不作为历史复习题源。只显示题目拼音，题目、教材所列朝代与作者和全文都由孩子默写，不播放语音。
7. 同一次默写中，只要任意默写字出现在课文题目里，页面主标题和该课所有题卡都会持续把对应字替换为拼音，避免其他题泄露答案；批改时恢复中文题目。
8. 孩子写完后点击“结束默写”，点选答案中的错字并完成批改。订正页显示整词和拼音，实际错字标红。词语第一次写错整词订正 2 遍，以后该题每错一次增加 1 遍。古诗订正按错字给出遍数。
9. 家长看板首页显示默写打卡日历，可切换月份查看打卡天数和每天的默写题次。“学习进度”按题目展示已掌握、待巩固和未练的词语，同时汇总所选教材的考察字总数和已练题的去重字覆盖。在“错题本”中可切换待巩固和全部历史错题，并按当前范围打印。
10. 当课复习或历史复习保存后如果漏标了错字，可在“家长看板 → 默写记录”找到对应记录，点击“补记错字”进入独立页面；较早的记录可先点“查看全部”。补记页面会列出当场题词，锁定已经记录的错字，并允许把其他原判正确的计分字补标为错误。更正会直接修改原记录：作答次数不增加，并同步更新待巩固状态。新记录会保存当场题词和实际计分字；旧记录按当前词库还原，原来判为全对的目标字可直接补记，无法证明当场计分的提示字保持不可选，旧版已整词计错的题不会重复累计。
11. 当课复习和历史复习的批改题卡下方可标记“组词不合适”“读音不准”，两项可同时选择，再次点击可取消。标记会自动保存，不计为孩子的错字。家长可在“家长看板 → 词库问题”集中查看、导出当前列表的 JSON 清单，并在修改词库后标记已处理；也可重新打开。记录保留标记时的完整词语、拼音、目标字和课次，即使重建词库仍可定位原题。

## 词库

当前题库以本次提供的五·四学制教材为准，覆盖二年级上下册、三年级上下册、四年级上册，不用旧教材补齐未提供的册次。

```bash
npm run rebuild:catalog
```

重建脚本默认从仓库的 `textbook/` 读取材料，也可传入其他教材目录。脚本从 `小学语文教材结构化/` 读取课次、识字表、写字表和古诗，从 `默写词库-教材入库.md` 读取册末词语、拼音和语境，并按课次文件核对词语顺序。运行中的服务重启后加载新词库。

识字表、写字表中未被本课词语表覆盖的字，在重建时从课文、列词和选字练习补题，并核对 `scripts/textbook/reviewed-prompts.json` 中的 282 条审阅数据。单字优先附完整原句，依教材版面接续换行或续页的原文。原教材只列词或篇名时，使用原有语境挖空。

教材库包含 `catalog_meta`、`source_files`、`lessons`、`lesson_characters` 和 `questions` 五张表。每道册末词、生字补充题或整篇古诗在 `questions` 中占一行，保存题目 ID、题词、拼音、提示、考察字和教材出处。当课和历史复习引用同一题目 ID。

- `data/ziqu-catalog.sqlite` 是从教材重建的只读词库，重建时先校验临时库再替换。
- `ZIQU_LEARNING_DB_PATH` 指向独立的学习库，默认文件为 `data/ziqu-learning-inherited-mastery.sqlite`，保存默写记录、题目成绩和具体错字。

## 学习记录

学习库保存已继承的逐字掌握记录，以及需要按新词语复练的错字对应题。同一道题可以承接多个错字。复练遵守五天间隔，完成整题判定后按这道题的实际成绩继续安排。整题尚无判定且全部考察字已继承的题，在家长页显示为「考察字已继承」。

可用以下命令查看学习库中按教材归类的逐字成绩。学习库和导出的报告含个人学习数据，请勿提交到仓库。

```bash
npm run --silent mastery:report -- data/ziqu-learning-inherited-mastery.sqlite
```

## 运行

运行环境使用 Node.js 24，前后端共用同一套出题规则。

```bash
npm install
npm run dev
```

然后打开终端中显示的本地地址。

启动页面只读取课次目录、当前课题目和必要的学习统计。切课和历史复习由后端按需返回题目，家长看板按需加载用于展示的题目和默写记录。词库查询结果在服务端缓存，接口支持 gzip 压缩，保存时合并尚未加载的近期默写记录。

生产运行：

```bash
npm run build
npm run start
```

## 代码结构与职责

```text
shared/
  types.ts                 词库、学习状态、默写记录的数据类型
  contracts.ts             HTTP 请求与响应的数据契约
  domain/
    characters.ts          目标字与整词字集、逐字批改键
    catalog.ts             课次范围、词语表与补充组词
    reviewPolicy.ts        掌握标准、历史错字复习间隔
    practice.ts            当课、历史、古诗等题目生成
    reviews.ts             批改结果与原记录补记
    state.ts / wordIssues.ts  状态归一化、词库问题标记
src/
  App.tsx                  页面装配与加载状态
  app/
    useLearningData.ts     加载、请求取消、延迟保存、页面数据合并
    useAppController.ts    页面切换、练习阶段、批改草稿与操作衔接
  features/practice/       默写、古诗题卡、订正、标题遮罩、语音播放
  features/parent/         家长看板、最近记录、补记页面
  components/              跨页面共用的界面组件
  lib/                     浏览器 API 适配、日期与课次展示
server/
  index.mjs / app.mjs      进程启动、服务装配与依赖注入
  routes/                  URL、HTTP 方法与业务服务的对应关系
  http/                    JSON、压缩、静态资源传输
  services/                词库缓存、出题与学习记录的业务编排
  db/                      SQLite 表结构、连接与读写
  config.mjs               数据路径与运行配置
```

依赖方向：`src → shared`，`server → shared`；`shared` 不依赖 React、HTTP、SQLite 或前后端目录。后端路由调用服务，服务调用数据库模块；界面组件通过回调触发操作，不直接请求接口。`src/lib/api.ts` 按 `shared/contracts.ts` 构造请求、读取响应；这些类型描述现有协议，运行时校验规则沿用原实现。

题目生成和完整词库缓存由后端负责，语音播放、提示、逐字选择和练习阶段由浏览器负责。批改与补记在浏览器调用共享规则后保存状态。

新增业务规则放到 `shared/domain` 的相应模块，新增页面放到对应 `features`，新增接口先更新 `shared/contracts.ts`。`src/lib/scheduler.ts`、`storage.ts`、`wordIssues.ts`、`src/types.ts` 和 `server/db.mjs`、`catalog.mjs` 保留为旧脚本的兼容导出入口，新代码优先引用具体模块。

验证命令：

```bash
npm test                 # 接口、数据库、业务规则与模块依赖边界
npm run prompts:audit    # 真实词库的题目与目标字检查
npm run --silent prompts:coverage  # 册末词语、当课和全册历史模拟题的单字及缺句清单
npm run build           # 严格类型检查、未使用代码检查、生产构建
```

## 部署到服务器

可以直接使用 Docker 启动网站：

```bash
docker compose up -d --build
```

默认访问端口是 `5174`。Compose 将 `ziqu-data` 数据卷挂到 `/var/lib/ziqu`，服务使用其中的 `ziqu-learning-inherited-mastery.sqlite` 保存学习记录。更新容器时继续挂载同一个数据卷。全新安装会自动初始化学习库。课本词库随镜像更新，播音由浏览器提供。
