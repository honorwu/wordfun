篇目按教材目录排序。目录中的合篇课文保留共同编号和一份篇目文档，子篇目保留原标题及各自起始页。正文内独立栏目在对应位置列出并注明目录收录情况。

来源页码同时给出教材印刷页和从首页起算的 PDF 页。链接定位到对应页段起始页。正文按印刷页分段，跨页句可顺接下一页。篇目页段可包含课后题或字表所在页，原文和节录各自标明实际出现的页。

按字词检索时可在学期文件夹全文搜索，或打开册末附表按字词定位对应篇目。写字、识字、词语分别沿用教材册末表的分类，节录也标注了原页和内容性质。
